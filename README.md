## 🧪 The game

You pilot a microscopic ship inside an atom. Every chemical element is its own level.

1. **Shoot orbiting electrons** out of their shells.
2. **Collect loose electrons** to earn upgrade currency.
3. Clear the shells and the **nucleus destabilizes and splits**.
4. **Collect blue neutrons** while avoiding dangerous red protons.
5. Survive the full collection window and satisfy the neutron objective.
6. Spend particles on **ships, weapons, engines, and modules**.
7. Progress from **Hydrogen to element 118**.

The post-split phase gives early atoms **60 seconds** and gradually decreases toward a **20-second minimum** for the hardest elements. Reaching the neutron quota does not instantly end the level, so you can continue collecting bonus particles until the timer expires.

## 🎵 Audio

Atom Shooter generates its soundtrack and sound effects with the browser **Web Audio API** instead of shipping copied audio from the historical Android game.

Browsers require a click, tap, or key press before audio can begin. Music is enabled by default and can be changed in **Options → Ambient music**.

## 🪟 Windows Releases

`.github/workflows/windows.yml` builds the portable Windows version when:

- `main` is updated;
- a version tag such as `v1.1.1` is pushed;
- the workflow is launched manually.

The build is configured to produce only:

```text
Atom-Shooter.exe
```

When a matching release already exists, the workflow **deletes old custom release assets first**. This removes obsolete files such as the previous versioned Windows EXE and `Atom-Shooter-Windows.exe`, then uploads the new `Atom-Shooter.exe`.

That keeps this permanent download URL stable across future versions:

**https://github.com/Draconov/Atom-Shooter/releases/latest/download/Atom-Shooter.exe**

The workflow verifies that `dist/Atom-Shooter.exe` exists before touching the release. A failed build therefore cannot silently publish an empty or incorrect project asset.

## ⚡ Performance

The renderer and game loop avoid unnecessary work by:

- pre-rendering the static arena background;
- caching electron-shell radii;
- tracking remaining orbiting electrons directly;
- skipping unchanged HUD DOM updates;
- bounding transient visual particles;
- avoiding nuclear-particle simulation before the nucleus splits;
- pausing procedural music scheduling while the page is hidden.

## 📜 Project scope

This repository is a newly written recreation based on the gameplay concept and compatibility/reference inspection of a user-supplied historical Android APK. It does **not** publish the original APK, recovered original source code, original music, or copied proprietary sprite resources.

“Atom Shooter” and the historical game remain associated with their original creators/rightsholders. If this project is distributed publicly under the original name or branding, make sure you have the necessary rights to do so.
